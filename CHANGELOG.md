# Development Changelog

## Part 3 – Milestone 1 (4 November 2026)
- Added a collapsible navigation menu for tablet and mobile screen widths across all five pages.
- Added an active-page indicator to the main navigation using `aria-current`.
- Added accessible menu state information with `aria-expanded` and an associated navigation label.
- Added visible keyboard focus styles for navigation, links, buttons and form controls.
- Improved responsive layout rules for page sections, cards, service rows, images and footer text.
- Added reduced-motion support for visitors who request less animation from their operating system.
- Added a unique meta description and theme colour metadata to each page.
- Improved selected image alternative text to describe the image content more clearly.
- Added `robots.txt` and `sitemap.xml` as initial search-engine support files.
- Created this README and a references document.
